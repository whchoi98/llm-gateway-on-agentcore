Architecture / Amazon Bedrock AgentCore Gateway

AgentCore LLM Gateway — architecture and request flow

One gateway in Seoul sends Claude 5.5, GPT 6.x and Kimi K3.1 requests to Bedrock Global CRIS first. On failure, Claude falls back to Claude Platform on AWS (1P) and GPT to Bedrock Mantle in us-east-1; Kimi has no fallback. Source: lib/ (CDK), lambda/.

Claude 5.5

Bedrock → Claude Platform on AWS

  • API: Anthropic Messages, Bedrock InvokeModel (premium scope)
  • Primary global.anthropic.claude-*-5-5
  • Fallback cponaws (the proxy λ adds the workspace header)
  • Tell: an id starting with msg_bdrk_ is 3P

GPT 6.x

Bedrock → Mantle us-east-1

  • API: Chat Completions, Responses
  • Primary global.openai.gpt-6*
  • Fallback mantle (data leaves for the US during a fallback)
  • Tell: model = openai.* means fallback

Kimi K3.1

Bedrock only, no fallback

  • API: Chat Completions, Responses
  • Primary global.moonshotai.kimi-k3.1
  • No fallback: Bedrock errors go straight back to the caller
  • Anthropic Messages gets a 400 with guidance, as for GPT
